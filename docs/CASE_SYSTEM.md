# KS3 — Система кейсов, скинов и экономики

## 1. Философия

- **No Pay-to-Win:** Только косметика
- **Честность:** Шансы открыты, pity, логи
- **Трейдабельность:** Все можно продать, кроме подарков
- **Крафт:** Мусор → золото

## 2. Валюты

- **Credits (CR):** Премиум, покупается за $, $1 = 100 CR. Для кейсов, баттлпасса.
- **Scrap (SC):** Фритуплей, за матчи, за разбор скинов. 1 матч ~15 SC. Для крафта.
- **Tokens:** Ивентовая, сгорает после ивента.

## 3. Редкости (6 уровней)

| Редкость | Цвет | Шанс в обычном кейсе | Цена маркета (avg) | Эффект открытия |
|---|---|---|---|---|
| **Common** | #B0C3D9 серый | 50% | $0.1-0.5 | Обычный свет |
| **Uncommon** | #5E98D9 синий | 25% | $0.5-2 | Синий glow |
| **Rare** | #4B69FF индиго | 12% | $2-10 | Фиолетовый трейл |
| **Mythic** | #8847FF пурпур | 7% | $10-40 | Розовый + звук |
| **Legendary** | #D32CE6 розовый | 4.5% | $40-200 | Золотой вихрь |
| **Immortal** | #EB4B4B красный + золото | 1.5% | $200-5000 | Красный взрыв, slow-mo, музыка |

- **Дополнительно:** StatTrak (10% шанс на любом), Gold edition (0.1% — золотой скин), Holo Foil наклейки.

## 4. Виды кейсов

| Кейс | Цена | Доступ | Содержимое |
|---|---|---|---|
| **Recruit Case** | Free, 1/неделю за 5 побед | Все | Common-Uncommon 90%, Rare 10% |
| **Spectrum Case** | 250 CR ($2.5) | Магазин | Все редкости, 2 Immortal ножа |
| **Fracture Case** | 250 CR | Магазин | Тематика Fracture, 2 Immortal перчатки |
| **Season Case** | 300 CR | 3 месяца | Скины сезона, нельзя получить после |
| **Event Case** | 350 CR или ивент токены | Ивенты | Лимитированные, 1 месяц |
| **Workshop Case** | 250 CR, 50% автору | Community | Лучшие скины комьюнити, голосование |

Каждый кейс — 15 скинов + 5 наклеек + 2 граффити + 1 брелок.

## 5. Механика открытия

### Клиент (анимация):
1. Нажал Open → запрос на сервер
2. Сервер возвращает itemId (уже выбран, но клиент не знает)
3. Клиент запускает рулетку: лента из 50 итемов, из них 1 реальный на позиции 42 (подстраивается)
4. Анимация: 6 сек, ease-out cubic, замедление, звук tick-tick-tick, в конце — вспышка по редкости
5. Reveal: 3D turntable модели, кнопка Inspect, Equip, Sell

### Сервер (честность):
```js
function rollCase(caseId, userId) {
  const pity = getPity(userId, caseId); // счетчик без Immortal
  let chances = baseChances;
  if (pity > 20) chances.Immortal += (pity-20)*0.2%; // pity
  if (pity > 30) chances.Immortal = 10%; // гарант
  const roll = rng(); // cryptographically secure
  // ...
  if (rarity === 'Immortal') resetPity(userId);
  else incPity(userId);
  logTransaction(userId, itemId, hashChain);
}
```

- **Pity:** После 25 кейсов без Legendary+ — шанс х2. После 40 без Immortal — гарант Immortal в след 10.
- **Provably Fair:** Каждый ролл хешируется SHA256 с server seed + client seed, игрок может проверить.

## 6. Содержимое детально

- **Скины оружия:** 3 слоя: base mesh + skin texture (albedo + normal overlay) + wear (0.0-1.0 float, как в CS). Паттерн индекс для каждого скина (как в CS).
- **Ножи:** 12 моделей, анимации inspect, разные редкости
- **Перчатки:** PBR, 8 моделей
- **Наклейки:** Можно клеить на оружие (4 слота), скретч эффект
- **Брелоки:** На оружии болтаются, физика
- **Граффити:** 1 использование, спрей на карту
- **Анимации:** MVP анимации, эмоции

## 7. Крафт и апгрейд

- **Trade-Up Contract:** 10 скинов одной редкости → 1 скин на уровень выше (из той же коллекции, 10% шанс StatTrak)
- **Scrap Craft:** 1000 SC + 5 Common → 1 Uncommon случайный
- **Upgrade:** Вставить 3 скина + CR → шанс апгрейда 30%/60%/90% в зависимости от CR. При неудаче — получаешь 50% SC назад.
- **Sticker Craft:** 5 наклеек → 1 случайная выше редкости

## 8. Маркетплейс

- **Листинг:** Выставляешь предмет, цена в CR, комиссия 10% (5% Valve + 5% KS3). Минимум $0.10
- **Escrow:** Трейды между игроками — 3 дня холд если нет 2FA, мгновенно если есть
- **Защита:** 
  - 2FA обязательно для >$100 инвентаря
  - API key с правами только чтение по умолчанию
  - ML детект скама: если трейд сильно невыгодный (>90% разницы) — предупреждение
  - Логин с нового IP — блок трейдов 7 дней
- **История:** График цены предмета, как в Steam

## 9. Кейс-ивенты

- **Golden Week:** Шанс Gold edition x2
- **Double Drop:** За победу — 2 кейса вместо 1 (выходные)
- **Workshop Battle:** Голосование за скины, топ-3 в кейс, авторы получают 25% от продаж

## 10. Экономика баланс

- **Inflation control:** 
  - 50% скинов, полученных из Recruit Case — нельзя продать 7 дней (soulbound неделя)
  - Комиссия сжигает 5% CR (не возвращается)
  - Крафт сжигает скины
- **F2P:** Игрок без доната получает ~1 Rare в месяц, ~1 Legendary в год через крафт

## 11. UI/UX кейсов

- Карточка кейса: 3D, голограмма, частицы, при наведении — tilt effect
- Рулетка: Лента с инерцией, звук по редкости, slow-mo для Immortal
- Инвентарь: Сетка, фильтры по редкости, оружию, сортировка по цене
- Открытие: Fullscreen, затемнение, фокус на ленте
