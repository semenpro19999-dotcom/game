# KS3 — Roadmap, Приоритеты, Таймлайн

## 1. Фазы разработки

### MVP (Minimum Viable Product) — 2 месяца — Цель: играбельный прототип 5×5

**P0 (Критично):**
- [ ] UE5 проект на базе Lyra Starter Game
- [ ] 1 карта de_dustline blockout (BSP, 2 плента, тайминги)
- [ ] 3 оружия: K-45, AK-R, M4-Spectr + нож + 1 граната (smoke)
- [ ] Базовые механики: стрельба, отдача, урон, бомба plant/defuse, экономика упрощенная
- [ ] 128-tick dedicated server, replication, lag compensation (из Lyra)
- [ ] Главное меню (веб-прототип в этом репо — DONE, UE5 — UMG с 3D фоном)
- [ ] HUD: HP, ammo, money, radar, timer
- [ ] 1 специализация (Breacher) для теста
- [ ] Локальный мультиплеер (listen server)

**P1:**
- [ ] 2 доп гранаты (flash, HE)
- [ ] Разрушаемые укрытия (1 тип)
- [ ] Матчмейкинг локальный (queue)
- [ ] Звук: выстрелы, шаги (Wwise)

**P2:**
- [ ] Кейс система (мок, без бэкенда)
- [ ] Инвентарь UI

**Выход MVP:** Можно играть 5×5 на одной карте, с ботами, без скинов. Видео геймплея.

**Таймлайн MVP (8 недель):**
- Неделя 1-2: Lyra setup, GDD финал, blockout карты, Blender — 1 оружие low poly
- Неделя 3-4: Стрельба, отдача, бомба, экономика, HUD
- Неделя 5-6: Сеть, 128-tick, сервер, античит EAC интеграция
- Неделя 7: Главное меню 3D, звук, специализация
- Неделя 8: Полиш, багфикс, запись трейлера MVP

## 5. Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| UE5 слишком сложный для соло | Высокая | Высокая | Использовать Lyra как базу, Blueprints, не писать с нуля |
| Читы убьют игру | Средняя | Критичная | EAC с дня 1, серверная валидация, ML позже |
| Нет игроков (CS2 доминация) | Высокая | Высокая | УТП: погода, разрушаемость, честный маркет, F2P, Workshop, киберспорт призовые |
| Контент долго делать (модели) | Высокая | Средняя | Procedural weapons (Geometry Nodes), покупка ассетов (Quixel, Sketchfab CC0) для прототипа, AI генерация концептов |
| Токсичность, смурфы | Средняя | Средняя | Анти-смурф ML, похвала система, ИИ-тренер для новичков |
| Юридические (Valve) | Низкая | Высокая | Не копировать ассеты, названия, все оригинальное, "духовный наследник" а не клон |
| Выгорание соло | Средняя | Высокая | Веб-прототип для быстрой дофаминовой отдачи, публичный девлог, итерации |
